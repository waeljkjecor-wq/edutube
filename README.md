# دروسي: يوتيوب وتيليجرام تعليمي آمن 📚

تطبيق أندرويد يعرض للطالب **فقط** ما يحدده المعلم أو ولي الأمر:
قنوات يوتيوب، ومجموعات وقنوات تيليجرام، واختصارات مجموعات واتساب.
ومعه تذكير بمواعيد الامتحانات، وجدول الدروس الأسبوعي.

## الأقسام (الشريط السفلي)

### 1. الدروس
- **يوتيوب**: قنوات وقوائم تشغيل وفيديوهات مسموحة فقط، ومشغّل مقفل (بلا تعليقات أو اقتراحات أو خروج إلى يوتيوب).
  - **عدد المشاهدات**: يُحسب كم مرة شوهد كل فيديو عبر التطبيق.
  - **ملء الشاشة**: زر يقلب الهاتف أفقياً.
  - بحث داخل الدروس المسموحة فقط.
- **تيليجرام**: المجموعات والقنوات التي يختارها المشرف فقط، **للقراءة فقط**.
  - نصوص، صور، فيديو، رسائل صوتية، وملفات **PDF تُفتح داخل التطبيق** (مع تكبير وتصغير).
  - الرسالة المثبّتة (مثل موعد الامتحان) تظهر في الأعلى.
- **اختصارات واتساب**: زر يفتح مجموعة الأستاذ مباشرة في واتساب.

### 2. الامتحانات
- بطاقة «الامتحان القادم» مع عدّ تنازلي بالأيام.
- إضافة امتحان: المادة، النوع، التاريخ، الوقت.
- **تذكير بإشعار** على الهاتف: قبل أسبوع، أو قبل يومين، أو قبل يوم، أو صباح يوم الامتحان (يعمل حتى لو كان التطبيق مغلقاً، ويستمر بعد إعادة تشغيل الهاتف).
- ضغطة مطوّلة على الامتحان لحذفه.

### 3. الجدول
- حصص كل يوم (الأحد إلى الخميس)، وتمييز الحصة الحالية بشارة «الآن».
- زر ▶ بجانب الحصة يفتح دروس يوتيوب المرتبطة بتلك المادة.
- تعديل الجدول من زر القلم (يحتاج رمز المشرف).

## لوحة المشرف (رمز PIN)
- إضافة وحذف قنوات يوتيوب وقوائم التشغيل والفيديوهات.
- **تيليجرام**: مفاتيح api_id و api_hash، ثم ربط الحساب، ثم اختيار المجموعات.
- **واتساب**: اسم المجموعة ورابط دعوتها.
- إحصائيات المشاهدة، وقفل الشاشة، وإخفاء Shorts، ومفتاح YouTube API (اختياري).

## إعداد تيليجرام (مرة واحدة)
1. ادخل [my.telegram.org](https://my.telegram.org) برقم أي حساب تيليجرام، ثم **API development tools**.
2. أنشئ تطبيقاً (أي اسم) وانسخ **api_id** و **api_hash**.
3. في «دروسي»: لوحة المشرف ← تيليجرام ← الصق المفتاحين ← «حفظ».
4. «ربط حساب تيليجرام» ← رقم الطالب ← رمز التحقق (يصل داخل تيليجرام أو SMS).
5. «اختيار المجموعات» ← ضع ✓ على مجموعة الأستاذ ← «حفظ».

> لا يرى الطالب داخل «دروسي» إلا ما اخترته. تطبيق تيليجرام الرسمي، إن بقي على الهاتف، يعمل كالمعتاد.

## التحميل
كل رفع للكود على فرع `main` يبني التطبيق تلقائياً.
آخر نسخة دائماً من: **Releases ← EduTube.apk**

- بدون مفتاح YouTube API يظهر آخر 15 فيديو من كل قناة.
- عند فتح اختصار واتساب يتوقف قفل الشاشة مؤقتاً (أندرويد يمنع فتح تطبيق آخر أثناء القفل)، ويعود عند الرجوع إلى «دروسي».
- ملف التوقيع `app/edutube.jks` في المستودع حتى تُثبَّت التحديثات فوق النسخة القديمة دون فقدان البيانات.
